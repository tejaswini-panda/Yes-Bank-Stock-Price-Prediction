# Yes Bank Stock Price Prediction

A Machine Learning regression project focused on predicting Yes Bank's stock closing prices using historical stock market data and predictive modeling techniques.

## 📌 Project Overview

This project analyzes historical Yes Bank stock price data to identify market trends and build a regression-based model for predicting the closing price. The workflow covers data preprocessing, exploratory data analysis, feature preparation, model development, and performance evaluation.

## 🎯 Objective

- Analyze historical Yes Bank stock price patterns.
- Perform data cleaning and preprocessing.
- Explore relationships between stock market features.
- Build regression models to predict the closing price.
- Evaluate model performance using suitable regression metrics.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Project Workflow

1. Data Collection
2. Data Understanding
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis
5. Feature Selection and Preparation
6. Regression Model Development
7. Model Evaluation
8. Prediction and Result Analysis

## 📊 Dataset

The project uses historical Yes Bank stock price data containing market-related features such as stock prices and trading information.

The dataset is included in this repository for reproducibility.

## 📈 Model Evaluation

The regression models are evaluated using appropriate performance metrics, including:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
